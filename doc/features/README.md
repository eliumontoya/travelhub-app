# TravelHub — Agencia de Viajes en una app

Crea, gestiona y comparte itinerarios de viaje profesionales con tus clientes, sin depender de plataformas de terceros ni pagar suscripciones mensuales.

TravelHub es tu herramienta todo-en-uno como agente de viajes independiente: CRM de clientes, constructor de itinerarios, portal público para el viajero y tablero de negocio.

---

## Features

| Feature | Para qué sirve |
|---|---|
| [Constructor de Itinerarios](./itinerary-builder.md) | Arma viajes día por día con vuelos, hoteles, actividades, restaurantes, transporte y notas |
| [Portal del Cliente](./client-portal.md) | Comparte una URL única y privada — tu cliente ve su viaje sin registro, sin contraseña, sin apps |
| [CRM de Clientes](./client-crm.md) | Ficha de cliente, historial completo de viajes, documentos adjuntos y métricas por cliente |
| [Dashboard de Negocio](./dashboard-analytics.md) | KPIs, tendencias, cumpleaños próximos, actividad reciente y explorador de viajes |
| [Calendario y Scheduling](./calendar-sync.md) | Sincroniza con el calendario personal de tu cliente — un clic, sin plugins |
| [Automatizaciones](./automations.md) | Recordatorios automáticos por email, plantillas reutilizables, duplicado de viajes |
| [Integraciones](./integrations.md) | Mapas embebidos, estado de vuelos en vivo, clima, y almacenamiento de documentos |
| [Herramientas Extra](./extras.md) | Galería de fotos, packing lists, vista cotización, encuestas post-viaje |

## ¿Qué lo hace diferente?

- **Sin dependencia externa.** Tu negocio no depende de que una plataforma de terceros suba el precio, cambie términos o cierre.
- **Sin registro para el cliente.** Tu cliente recibe una URL y ya — ni cuenta, ni contraseña, ni app que instalar.
- **Modo offline-ready.** TravelHub funciona completo con datos de prueba aunque no tengas conexión a Supabase. Todo lo que necesitas es `npm run dev`.
- **Hecho para crecer.** Arquitectura limpia lista para sumar cotizaciones, pagos o app móvil cuando tu negocio lo pida.
