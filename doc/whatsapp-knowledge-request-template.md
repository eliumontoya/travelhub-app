# Solicitud de información para configurar el agente de WhatsApp

Hola, equipo.

Estamos preparando un agente de WhatsApp para responder automáticamente preguntas frecuentes de clientes y escalar a una persona cuando la solicitud requiera atención humana.

Para configurarlo correctamente, necesitamos que nos compartan información oficial, actualizada y aprobada por la empresa. La idea es que el agente solo responda con información validada y no prometa nada que no esté confirmado.

## Cómo llenar este documento

- Responder solo con información oficial.
- Si un tema no aplica, escribir `No aplica`.
- Si el agente no debe responder algo automáticamente, indicarlo claramente.
- Si una respuesta depende de disponibilidad, precio, fecha o caso particular, indicar que debe escalarse a un asesor.

## 11. Respuestas preaprobadas

Si ya existen mensajes oficiales, compartirlos con este formato:

```txt
Título:

Pregunta o intención que responde:
Respuesta aprobada:
Condiciones para usarla:
Cuándo NO usarla:
¿Debe escalar después de responder? Sí / No
```

Ejemplo:

```txt
Título: Horario de atención
Categoría: FAQ
Pregunta o intención que responde: Cuando pregunten por horarios.
Respuesta aprobada: Nuestro horario de atención es de lunes a viernes de 9:00 a 18:00 y sábados de 10:00 a 14:00.
Condiciones para usarla: Cuando el cliente pregunte por horarios generales.
Cuándo NO usarla: Si el cliente reporta una emergencia durante su viaje.
¿Debe escalar después de responder? No
```

## Resultado esperado

Con esta información podremos crear una base de conocimiento fija para que el agente de WhatsApp pueda:

- responder preguntas frecuentes,
- pedir datos faltantes,
- evitar prometer información no confirmada,
- escalar correctamente a un asesor,
- registrar intención e interacción para seguimiento posterior.
